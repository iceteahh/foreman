# 2026-09-02 — checkout returning 500s under load

## Impact
The `/price` endpoint returned HTTP 500 for roughly 4% of requests for 22 minutes
during the morning peak. No orders were lost; the client retried.

## What happened
The service crashed with `fatal error: concurrent map writes` and was restarted
by the supervisor eight times. Each crash dropped the in-flight requests.

## Follow-up
- [ ] Decide whether the price cache should be made safe for concurrent use.
- [ ] Add a load test that exercises the endpoint from more than one connection.
